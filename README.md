## Suggested Practice Routine

1. Learn one concept and write a short note.
2. Implement it in C++ and save the source file in this repository.
3. Solve a few problems that use the concept.
4. Record the problem link, approach, and complexity in your notes.
5. Mark the checkbox only after you can explain and implement the concept yourself.
